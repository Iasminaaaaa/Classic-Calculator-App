> The Classic Calculator App is a straightforward and reliable tool for everyday math. It features basic arithmetic operations: addition, subtraction, multiplication, and division along with reciprocal calculation, square root, and square functions.

## Install

```
Clone the repository:

git clone https://github.com/Iasminaaaaa/Classic-Calculator-App.git

Open the project folder in Visual Studio Code.

Open the terminal in VS Code and compile the application using g++:

g++ -o Calculator main.cpp

Run the application:

./Calculator

Or on Windows:

Calculator.exe
                
```

## Usage

```
After launching the Classic Calculator App, you can:

🧮 Perform basic arithmetic operations: addition (+), subtraction (−), multiplication (×), and division (÷).

📐 Calculate square roots and squares of numbers.

🔁 Find the reciprocal of any number.

🟰 View the result by pressing the = key.

❌ Clear the calculator or close the application using X or C.

All operations are done instantly within the console interface, making it a lightweight and reliable offline tool for quick calculations.               
```
